# 🦫 Лосяш (Losyash Router)

Голосовой ассистент для интеграции локального распознавания речи (Whisper) с большими языковыми моделями (Ollama / Qwen) для управления умным домом.

## 🚀 Возможности
- 🎙️ **Локальный захват звука**: Запись голоса через подсистемы Windows DirectSound/WASAPI с автоматическим отсечением тишины.
- 🧠 **Распознавание речи**: Быстрая локальная обработка голоса с помощью модели Whisper (small, CUDA).
- 💬 **Умный собеседник**: Генерация ответов на базе локального сервера Ollama и модели Qwen 2.5 (7B).
- 🏠 **Интеграция**: Готовность к интеграции с Home Assistant и умными колонками через кастомные сценарии.

## 🛠️ Требования и окружение
- **ОС**: Windows 10 / 11
- **Интерпретатор**: Python 3.12+
- **Оборудование**: Рекомендуется видеокарта с поддержкой CUDA (для работы Whisper)
- **Зависимости**: `sounddevice`, `numpy`, `numpy.core`, `ollama` (или `requests`)

## 📦 Быстрый старт

### 1. Подготовка окружения Windows
Убедитесь, что в настройках конфиденциальности Windows разрешен доступ классических приложений к микрофону.

### 2. Установка зависимостей
Установите необходимые библиотеки через терминал:
\`\`\`bash
pip install sounddevice numpy ollama
\`\`\`

### 3. Запуск локального ИИ-сервера
Скачайте Ollama и запустите модель:
\`\`\`bash
ollama run qwen2.5:7b
\`\`\`

### 4. Запуск ассистента
\`\`\`bash
python losyash_router.py
\`\`\`

## ⚙️ Калибровка чувствительности
Если скрипт бесконечно слушает или не замечает голос, отрегулируйте переменную `ENERGY` в файле `losyash_router.py`. 
- Для тихих микрофонов: `0.005`
- Для шумных комнат: `0.05`
